| Сторінка | Файл | Адреса |

| Послуги | `services.html` | https://villevian.github.io/red-panda-design/services.html |
| Роботи | `work.html` | https://villevian.github.io/red-panda-design/work.html |

Кожна сторінка — окремий самодостатній HTML-файл без збірки та залежностей (крім шрифтів Google Fonts).

## Що замінити перед запуском

- `[ваш email]`, `[ваш номер]`, посилання на соцмережі (`href="#"`)
- Портфоліо на `work.html` і блок «Вибрані роботи» на `index.html` — зараз там приклади
- Ціни на `pricing.html` — зараз там приклади
- Форма на `contact.html` поки лише показує екран подяки, нікуди не надсилає дані
